# Clipboard test pages

A small static site for comparing native iOS Copy across a plain paragraph, a textarea, and a contenteditable region.

Each source type has separate ordinary-text and synthetic-marker pages. No JavaScript, clipboard handlers, forms, analytics, remote resources, or automatic data submission. Editing a field changes only the current page.

The marker is synthetic. No tenant identifiers, account names, credentials, logs, or customer data are included.

Expected allow/block behavior is determined by the tester's deployed app protection and content policies, not by this website. Copy with the iOS system menu and compare the same source text, work identity, and managed destination application.

Case IDs: A1/A2 plain, B1/B2 textarea, C1/C2 contenteditable.
